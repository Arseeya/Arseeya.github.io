1.3.0.2.test

2026-10-07

10.31 MB · 测试版 · 因 GitHub 故障暂未上传

新增功能

  • App 锁：6 位数字密码 / 指纹 / 人脸解锁；自动锁定时间（立即 / 30 秒 / 1 分钟 / 5 分钟 / 从不）；密保问题找回；连续输错 5 次锁 30 秒
  • 存储空间管理：展示 App 数据、缓存、相册、手机总空间；分类清理；图片保存位置可选（App 内部 / 系统相册）
  • 本地图片缓存：收发图片自动缓存，断网也能看，减少流量
  • 搜索用户：联系人页新增入口，输用户名直接发好友请求
  • 个人资料：支持修改头像、用户名、个性签名
  • 设置页面重构：通用 / 安全 / 高级 / 开发者选项
  • 权限与存储引导：首次启动引导页
  • 网络自动重连：Wi-Fi / 流量切换自动重连，飞行模式恢复后重连

优化改进

  • 聊天界面：消息排序、时间分组、已读标记、引用回复、长按菜单、未读角标、网络状态提示
  • 深色模式适配（我的 / 设置 / 加密 / 聊天 / App 锁 / 权限向导 / 登录注册）
  • 修复浅色模式下部分页面输入框文字看不见
  • 加密：关于界面显示对方版本号；探测消息带版本号；强制加密开关；取消特定用户加密
  • 运行报告内容扩展

Bug 修复

  • 浅色模式下部分页面输入框文字看不见
  • App 锁密码可超出 6 位
  • 两次密码不一致仍显示"App 锁已开启"
  • 自动锁定整行无法点击
  • 登录界面无法显示已输入文字
  • 私聊发送图片后自己看不见
  • 应用图标重复显示
  • 消息重复显示

已知问题

  • 部分旧版本（1.2.0.beta ~ 1.2.9.1.test）用户加密消息可能显示异常
  • 深色模式下部分二级页面尚未适配
  • 朋友圈功能尚未完整实现
  • 群组管理功能尚未实现
