版本历史

1.3.0.3.test 2026-10-10 · 10.31 MB · 测试版

因 GitHub 故障暂未上传

新增功能

  • 多服务器支持：设置 → 通用设置 → 服务器设置；支持手动切换主服务器（buer.kdns.fr）和备用服务器（buer.sswwgzs.cn）；切换后自动断开连接、清除登录状态、跳转重新登录；首次启动引导新增"服务器提醒"步骤
  • 图片缓存与双重引用：发送/接收图片自动缓存，断网也能看；缓存优先，失效则引用内部相册副本；图片查看页新增"保存到相册"按钮
  • 缓存分类清理：存储空间页新增图片缓存单独统计；清理时分别提示风险
  • 引导流程优化：扩展为 3 步（权限申请 → 存储位置选择 → 服务器提醒）；完成后无论升级都跳过

优化改进

  • 图片缓存目录：/data/data/link.arseeya.fzxkzd/cache/img_cache/
  • 图片缓存元数据：记录缓存文件与相册副本的映射关系
  • 发送图片：先保存缓存 → 读取 Base64 上传 → 本地消息引用缓存路径
  • 接收图片：下载到缓存 → 显示 → 后续引用本地路径
  • ApiClient 改为动态获取服务器地址（从 ServerManager 读取）
  • WebSocketManager 每次连接前重新读取当前服务器地址
  • 切换服务器时自动更新连接地址
  • 修复 AlertDialog 主题不兼容问题（改用系统原生）

Bug 修复

  • 图片发送后自己看不见
  • 图片缓存无法单独清理
  • 缓存清理无风险提示
  • ApiClient 无法使用当前服务器

已知问题

  • 部分旧版本（1.2.0.beta ~ 1.2.9.1.test）的加密消息可能显示异常
  • 深色模式下部分二级页面尚未适配
  • 朋友圈、群组管理、阅读功能尚未完整实现

下一步计划

聊天记录回收站 · 导出聊天记录备份 · 朋友圈完整功能 · 群组管理 · 阅读功能 · 报告系统 · 敏感词检测 · 发布签名版 APK

1.3.0.2.test 2026-10-07 · 10.31 MB · 测试版

因技术原因，该版本安装包已被删除且无法找回，永久不提供下载。

新增功能

  • App 锁：6 位数字密码 / 指纹 / 人脸解锁；自动锁定时间（立即 / 30 秒 / 1 分钟 / 5 分钟 / 从不）；密保问题找回；连续输错 5 次锁 30 秒
  • 存储空间管理：展示 App 数据、缓存、相册、手机总空间；分类清理；图片保存位置可选（App 内部 / 系统相册）
  • 本地图片缓存：收发图片自动缓存，断网也能看，减少流量
  • 搜索用户：联系人页新增入口，输用户名直接发好友请求
  • 个人资料：支持修改头像、用户名、个性签名
  • 设置页面重构：通用 / 安全 / 高级 / 开发者选项
  • 权限与存储引导：首次启动引导页
  • 网络自动重连：Wi-Fi / 流量切换自动重连，飞行模式恢复后重连

优化改进

  • 聊天界面：消息排序、时间分组、已读标记、引用回复、长按菜单、未读角标、网络状态提示
  • 深色模式适配（我的 / 设置 / 加密 / 聊天 / App 锁 / 权限向导 / 登录注册）
  • 修复浅色模式下部分页面输入框文字看不见
  • 加密：关于界面显示对方版本号；探测消息带版本号；强制加密开关；取消特定用户加密
  • 运行报告内容扩展

Bug 修复

  • 浅色模式下部分页面输入框文字看不见
  • App 锁密码可超出 6 位
  • 两次密码不一致仍显示"App 锁已开启"
  • 自动锁定整行无法点击
  • 登录界面无法显示已输入文字
  • 私聊发送图片后自己看不见
  • 应用图标重复显示
  • 消息重复显示
